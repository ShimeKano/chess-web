# Chess Web

A simple and accessible online chess platform designed for easy-to-play competitive chess.

* Create an account and start playing instantly.
* Play chess against other players.
* ELO rating and global player leaderboard.
* Match history and player statistics.
* Stockfish-powered move analysis.
* Move accuracy percentage for every game.
* Cheat detection and suspicious-game monitoring.
* Save and review previous games.
* FEN support and chess position tools.
* Responsive design for desktop and mobile.
* Fast client-side chess engine powered by Stockfish WebAssembly.

Built to provide a lightweight, easy-to-use chess experience while keeping competitive ratings and game history organized.
